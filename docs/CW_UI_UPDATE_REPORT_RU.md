# Отчёт: обновление диалогов NPC, планшета и редактора анимаций

Дата: 2026-10-21.

## Что сделано

### Общий стиль интерфейса
- Новый [CwUi.java](../src/main/java/ru/admincontrol/client/CwUi.java): золотая рамка диалогов с угловыми орнаментами, синяя рамка планшета, разделитель, кнопки с состояниями (обычная / наведение / фокус / недоступна), иконки (чат, «?», «…», закрыть, играть, плюс), 3D-бюст NPC.
- Голова модели следует за курсором в ограниченных углах (смещения курсора обрезаются), модель показывается как бюст с обрезкой по окну.

### Диалог с Луи (3 состояния) — [CwStoryStartScreen.java](../src/main/java/ru/admincontrol/client/CwStoryStartScreen.java)
- A (сюжетка недоступна): только «Закрыть», текст «Сейчас я занята другими делами…» — без слов «сюжет», «квест», без спойлеров.
- B (первый запуск): «Начать» и «Закрыть».
- C (есть прогресс): «Продолжить» и «Закрыть».
- Состояние выбирает сервер, тексты — в [CwStoryEntryService.java](../src/main/java/ru/admincontrol/cw/CwStoryEntryService.java). Клиент не может подменить действие (nonce, срок 30 с, как и раньше).
- Администраторский тест сохранил кнопку «Начать заново».
- Имя в окне — «Луи», как на третьем референсе.

### Универсальный диалог NPC — [CwDialogueScreen.java](../src/main/java/ru/admincontrol/client/CwDialogueScreen.java)
- Первое окно: имя, роль, текст, разделитель, кнопки ответов (до 12, не ровно два).
- После первого ответа окно становится историей: лица NPC и игрока, разные цвета и подложка, прокрутка колесом, полоса прокрутки, автопрокрутка вниз, кнопка «Свернуть/Развернуть» (компактная панель без модели), крестик.
- Короткая надпись кнопки и полная реплика в истории — отдельные поля (как и раньше).
- Экран возрождения [CwRespawnScreen.java](../src/main/java/ru/admincontrol/client/CwRespawnScreen.java) переведён на тот же стиль; исправлены опечатки «наза».

### Планшет — [CwGraphScreen.java](../src/main/java/ru/admincontrol/client/CwGraphScreen.java)
Переписан по первому референсу: верхняя панель со вкладками (Сцены, NPC, Диалоги, Задания, Условия, Действия, Предметы, Локации, Настройки), список модулей слева (фильтруется вкладкой, клик центрирует холст), холст с сеткой, масштабом, перемещением, ортогональными линиями со стрелками, мини-картой, undo/redo, копированием, удалением, связыванием; справа «Настройки элемента»; внизу библиотека элементов по 8 категориям и предпросмотр (модель NPC, текст, кнопки ответов, подключённые к диалогу).

### Редактор анимаций (как в Blockbench) — [CwAnimationEditorScreen.java](../src/main/java/ru/admincontrol/client/CwAnimationEditorScreen.java)
- 3D-viewport с живой моделью (ваш игрок или выбранный NPC), ПКМ — камера, колесо — масштаб.
- Выбор части кликом по модели или в дереве костей (12 костей, включая слои); вращение мышью по выбранной оси X/Y/Z и точными числами, кнопки ±5°, лимит ±180°.
- «Добавить позу / кадр» копирует текущую позу; таймлайн кадров; длительность перехода, 5 типов плавности; порядок кадров ← →; удаление.
- Предпросмотр, пауза (и Пробел), «Повторять», «Подтвердить», «Отменить».
- Библиотека циклов на диске (`config/admincontrol/animations/*.json`): сохранить, открыть, копия, удалить.
- «Привязать к NPC» отправляет цикл на сервер ([CwAnimationService.java](../src/main/java/ru/admincontrol/cw/CwAnimationService.java)); сервер проверяет права (ГА+), чистит данные, сохраняет в `npcs.json` и рассылает всем клиентам (и при входе игрока). Клиент проигрывает цикл на модели NPC ([PlayerEntityModelMixin.java](../src/main/java/ru/admincontrol/mixin/client/PlayerEntityModelMixin.java), [CwNpcAnimations.java](../src/main/java/ru/admincontrol/client/CwNpcAnimations.java)).
- Модель данных и интерполяция общие для редактора и игры: [CwAnimation.java](../src/main/java/ru/admincontrol/cw/CwAnimation.java).

### Сборка
- В [build.gradle](../build.gradle) добавлен `include` для Fabric API: Fabric API вложен в JAR (jar-in-jar), в игре нужен только Fabric Loader 1.20.1.

## Новые пакеты и данные
- `cw_anim_bind` (клиент → сервер), `cw_anim_sync` (сервер → клиент).
- Поле `animJson` у NPC в `npcs.json` (старые файлы читаются: поле необязательное).
- Новых команд и permissions нет; привязка анимации требует ранга ГА+ (как редактор графа).
