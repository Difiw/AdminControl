# Admin Control CW Expansion 1.1.0

Реализовано в существующем моде Fabric 1.20.1, без отдельного проекта.

## Доступ

- Senior (ур. 4): `/cw help`, `status`, `diagnose`, просмотр story/admin и безопасная помощь.
- ZGA (ур. 6): подтверждённые изменения сюжета, инвентаря и XP.
- Tech (ур. 7): reload и изолированный story test.
- GA/Developer (ур. 8/9): кисточка, схемы и полный реестр CW NPC.
- Blogger исключён из CW независимо от числового положения его уровня.

`/ahelp` фильтрует новые группы по фактическому рангу. Каждый узел Brigadier дополнительно имеет серверную проверку.

## Ограничения

- Ридер/писатель использует Sponge Schematic v2 и принимает v2/v3 с основной палитрой BlockData. Сущности не сохраняются. Block entity NBT обнаруживается и показывается предупреждение, но не вставляется.
- Rollback вставки не заявлен. Вставка пакетная и отменяемая только для ещё не поставленных блоков.
- Админские inventory/story-команды работают только для игроков онлайн, чтобы не повреждать офлайн playerdata.
- Ручной игровой smoke-test требует отдельного тестового мира; реальные миры при сборке не открывались.
