# Admin Control 1.0.0

Admin Control — мод для Minecraft 1.20.1 на Fabric, объединяющий инструменты администрирования и модерации, игровые системы и расширение CW/Lumira. Мод работает в одиночной игре, в мире, открытом по LAN, и на выделенном сервере. Для клиентских интерфейсов, моделей, текстур и синхронизации CW мод должен быть установлен и на клиенте, и на сервере.

> **Нужна готовая версия без компиляции?** Откройте ветку **[launcher-ready](https://github.com/Difiw/AdminControl/tree/launcher-ready)** и скачайте готовый `admin-control-1.0.0.jar`.

## Назначение

Проект предназначен для владельцев и администраторов серверов Minecraft 1.20.1, которым нужны управление правами, модерация игроков, журналирование действий и дополнительные игровые механики в одном Fabric-моде.

## Основные возможности

- администраторы, ранги и настраиваемые права;
- баны, предупреждения, муты и журналирование действий;
- управление игроками, инвентарями, телепортацией и серверными настройками;
- внутриигровые интерфейсы для администрирования;
- аукцион, магазин, кланы, монеты, задания и система навыков;
- античит-проверки и инструменты проверки файлов;
- CW Expansion: NPC, диалоги, сюжетные графы, точки сохранения и схематики;
- измерение и контент Lumira, собственные блоки, предметы, рецепты и ресурсы;
- раздельное хранение данных для каждого мира.

Полный список команд доступен в игре через `/ahelp`, `/phelp` и `/cw help`. Первого администратора можно назначить командой `/add_admin <ник>`.

## Текущая версия

- релиз Admin Control: **1.0.0**;
- Minecraft: **1.20.1**;
- Fabric Loader: **0.16.14 или новее**;
- Fabric API: **0.92.2+1.20.1** (включён внутрь релизного JAR);
- Java: **17**.

Версия задаётся свойством `mod_version` в `gradle.properties` и входит в имя готового файла: `admin-control-1.0.0.jar`.

## Ветки репозитория

- **main** — проверенный исходный код стабильной версии 1.0.0;
- **branch** — копия стабильной версии, от которой ведётся дальнейшая разработка;
- **launcher-ready** — только готовый JAR и краткая инструкция для пользователей, без исходников и промежуточных файлов.

## Системные требования

### Для готовой версии

- Minecraft Java Edition 1.20.1;
- Fabric Loader 0.16.14+;
- Java 17, используемая Minecraft;
- Windows, Linux или macOS, поддерживаемая Minecraft/Fabric.

Среда разработки, Gradle и самостоятельная компиляция не требуются.

### Для сборки исходников

- 64-битная JDK 17;
- Git;
- подключение к интернету при первом запуске Gradle (зависимости сохраняются в кэше);
- не менее 2 ГБ свободной оперативной памяти для Gradle.

## Как скачать исходники

Через Git:

```bash
git clone https://github.com/Difiw/AdminControl.git
cd AdminControl
git switch main
```

Либо откройте ветку `main` на GitHub, нажмите **Code → Download ZIP** и полностью распакуйте архив.

## Как собрать проект

В Windows PowerShell или Command Prompt:

```powershell
.\gradlew.bat clean build
```

В Linux/macOS (после выдачи права на запуск wrapper):

```bash
chmod +x gradlew
./gradlew clean build
```

Gradle Wrapper сам загрузит Gradle 8.8. Тесты выполняются задачей `build`; отдельно их можно запустить командой `./gradlew test` или `.\gradlew.bat test`. Релизный файл появится по адресу `build/libs/admin-control-1.0.0.jar`. Файл с суффиксом `-sources` предназначен для разработчиков и не устанавливается в игру.

## Как установить и запустить готовую версию

1. Установите Fabric Loader для Minecraft 1.20.1.
2. Скачайте ветку **[launcher-ready](https://github.com/Difiw/AdminControl/tree/launcher-ready)** через **Code → Download ZIP** и распакуйте архив.
3. Скопируйте `admin-control-1.0.0.jar` в папку `mods`:
   - Windows: `%APPDATA%\.minecraft\mods\`;
   - Linux: `~/.minecraft/mods/`;
   - macOS: `~/Library/Application Support/minecraft/mods/`;
   - сервер: `<папка сервера>/mods/`.
4. Запустите профиль Fabric 1.20.1 в Minecraft Launcher или обычный стартовый файл Fabric-сервера.

JAR мода не является самостоятельным приложением и не запускается двойным щелчком: его загружает Minecraft через Fabric Loader. Fabric API уже упакован внутрь JAR; отдельная компиляция не нужна.

## Данные и конфигурация

Данные мира создаются только во время игры и не входят в репозиторий. Основные файлы находятся в `<папка мира>/admin_control/`, а общие ресурсы CW — в `config/admincontrol/`. Никогда не публикуйте содержимое игровых миров и серверных каталогов: они могут содержать UUID игроков, IP-адреса, пароли и журналы действий.
