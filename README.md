# Admin Control 1.0.0 — готовая версия

Эта ветка содержит только готовый Fabric-мод для Minecraft 1.20.1. Исходный код находится в ветках [main](https://github.com/Difiw/AdminControl/tree/main) и [branch](https://github.com/Difiw/AdminControl/tree/branch).

## Скачать

Нажмите **Code → Download ZIP**, полностью распакуйте архив и используйте файл `admin-control-1.0.0.jar`.

Прямая ссылка на JAR: [скачать admin-control-1.0.0.jar](https://github.com/Difiw/AdminControl/raw/launcher-ready/admin-control-1.0.0.jar).

## Установка и запуск

1. Установите Minecraft Java Edition 1.20.1 и Fabric Loader 0.16.14 или новее.
2. Скопируйте `admin-control-1.0.0.jar` в папку `mods` клиента и сервера:
   - Windows: `%APPDATA%\.minecraft\mods\`;
   - Linux: `~/.minecraft/mods/`;
   - macOS: `~/Library/Application Support/minecraft/mods/`;
   - сервер: `<папка сервера>/mods/`.
3. Запустите профиль Fabric 1.20.1 в Minecraft Launcher или стартовый файл Fabric-сервера.

Fabric API 0.92.2+1.20.1 и ресурсы мода уже включены в JAR. Среда разработки, Gradle и компиляция не нужны. Java 17 должна быть настроена для Minecraft/Fabric.

> `admin-control-1.0.0.jar` — это мод, а не самостоятельная программа. Его не нужно открывать двойным щелчком; файл загружается игрой через Fabric Loader.
